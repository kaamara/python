# TechWorld with Nana: kurs Pythona

Moje ćwiczenia z kursu [Python Tutorial for Beginners (TechWorld with Nana)](https://www.youtube.com/watch?v=t8pPdKYpowI).

## Struktura

| Folder | Temat | Pliki |
|---|---|---|
| `01_basics/` | zmienne, funkcje, pętle, sety | `days_to_hours.py`, `sets.py` |
| `02_modules/` | własne moduły, słowniki | `main.py`, `helper.py` |
| `03_datetime/` | moduł `datetime` | `time_till_deadline.py` |
| `04_oop/` | klasy i obiekty | `main.py`, `user.py` |

## Uruchamianie

Wejdź do folderu lekcji i odpal plik, np.:

```bash
cd 02_modules
uv run main.py
```

Bez `uv` zadziała też zwykłe `python main.py`.
